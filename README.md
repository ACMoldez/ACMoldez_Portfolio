# My Portfolio

My very first officially published project : a personal portfolio built from scratch using HTML, CSS, and JavaScript.

## About the Project

Inspired by retro games and cozy pixel-art worlds, this portfolio combines a pastel aesthetic with interactive storytelling to create a more personal way of presenting myself, my skills, and my work.

Featuring a **Story Mode**, interactive dialogue, unlockable memory cards, and a quest progress tracker, the website takes inspiration from classic games to make exploring my portfolio a little more engaging.

## Tech Stack
- **HTML5** — Website structure and content
- **CSS3** — Styling, layouts, animations, and visual design
- **JavaScript** — Interactive elements, dialogue system, and story progression

## Design Style
- Pastel colors and cozy visuals
- Retro-inspired, 16-bit aesthetics
- Game-inspired interactions and storytelling

## Purpose

This project is an opportunity to apply what I'm learning in web development while creating something that reflects my personality and creativity. It's a work in progress that will continue to evolve as I develop my skills and improve the experience.
